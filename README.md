# Pomodoro Timer 🍅
A simple Pomodoro Timer built with Python to help me stay focused while studying.

## About
This project uses the Pomodoro technique to divide study time into focused work sessions and breaks. I created it as a personal study tool while practicing my Python programming skills.

## Features
- ⏱️ Timed study sessions
- ☕ Short breaks between sessions
- 🌴 Longer breaks after multiple sessions
- 🔄 Automatically cycles between work and break periods
- 📚 Designed for studying and focused work

## How It Works
The timer follows the Pomodoro technique:

1. Study/work for a set amount of time.
2. Take a short break.
3. Repeat the cycle.
4. Take a longer break after several work sessions.

## Technologies
- Python

Make sure Python is installed,
